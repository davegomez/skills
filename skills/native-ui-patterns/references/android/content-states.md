# Android content and state

## Guidance

**Observed:** Settings grouped title/summary rows in rounded containers; Clock used alarm cards with nested controls. Messages, Contacts, and Files explained empty collections. Messages, Clock, and Contacts retained prominent creation actions. Maps/Phone/Clock/Settings combined visible selected/off cues with hierarchy state. **Inferred adaptation:** group by task, separate row and nested-control targets, name empty conditions, reserve emphasis for one main action, and express state beyond color. Populated counterparts, toggle changes, loading/failure, and selection remain **Unconfirmed**.

## Review checks

Check applicable loading, empty, populated, selected/unselected, checked/unchecked, action-activated, and unavailable states. UI hierarchy attributes do not establish TalkBack behavior.
