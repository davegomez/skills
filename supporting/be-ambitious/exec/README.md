# Execution test: ORIGINAL vs REWRITE prompt

1. Needs Node 24 (native TS for `node --test`), a global `tsc`, Python 3, Google Chrome, `sips`, `cwebp`. Lighthouse 13.5 lives in `tools/` (run `npm install` there once). Run every command here from `exec/`. Install the wrapper as a symlink, so it finds `tools/node_modules` beside its real path: `mkdir -p /tmp/ambition-exec/bin && ln -sf "$PWD/tools/lighthouse" /tmp/ambition-exec/bin/lighthouse`.
2. Build the fixtures with `python3 -I build_fixtures.py` (deterministic files, offline; it commits each fixture inside itself, so `fixtures/` holds 3 nested git repositories and is not tracked). Measure the X3 baseline with `python3 -I judges/judges.py x3 fixtures/fixture-site 18101 > judges/x3-baseline.json`.
3. One run plus judge: `python3 -I execute.py run X1 REWRITE 1`. Every missing run, cost-gated ($6 per run, $40 total): `python3 -I execute.py batch`. Tables: `python3 -I execute.py report` (it keeps the `<!-- summary -->` block in `results.md`).
4. A rerun skips any run that already has `runs/<id>.json`; delete that file to redo the run. Runs work in `/tmp/ambition-exec/<fixture>-<arm>-<n>/`, with a private `$TMPDIR` under `/tmp/ambition-exec/t/`. Keep that path short: past about 30 characters, the sandbox silently falls back to the shared `/tmp/claude-<uid>`.
5. Prompts are frozen in `prompts/` on first use: the cases from `../cases/T01|T04|T11.txt`, and the rewrites from the first fenced block of `../eval/calibration-runs/v7/T01|T04|T11-claude-1.md` (all three graded pass).
6. Executor: `claude -p --restricted --safe-mode --strict-mcp-config`, Opus 5.5 at effort high, with the prompt sent as stream-json on stdin and replayed into the transcript. Bash runs in the OS sandbox (no network, writes only in cwd and tmp). `policy()` in `execute.py` answers each permission prompt and logs it. Only Lighthouse on localhost runs outside the sandbox.
7. The judges in `judges/` never enter a fixture. The raw logs in `runs/` (64 runs, including the superseded harnesses v1-allowlist, v2-shared-tmp, and v2-tmp-leak) were deleted on 2026-10-19; their tables stay in `results.md`. `execute.py` counts their $32.53 in `DELETED_USD`, so `batch` sees $34.03 of the $40 cap as spent, and `report` refuses to run until `runs/` has a run summary again.
