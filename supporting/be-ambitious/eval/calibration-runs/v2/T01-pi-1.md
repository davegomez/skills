```text
The intended result is a narrowly scoped, regression-tested fix for callers of this helper. No additional product goals are assumed.

Use the existing implementation and JavaScript's native String.prototype.trim() as the behavioral baseline:
1. Add a null regression test expecting exactly "—". Run it against the original helper and confirm it fails because the helper throws.
2. Check the preservation assumption with representative non-null strings: empty, whitespace-only, already trimmed, leading/trailing whitespace, internal whitespace, and Unicode whitespace. Compare each result with that input's native trim() result. Include the string "null" to guard against confusing a string with the null value.
3. Make the smallest fix: handle null explicitly and retain the existing trim() call for strings.
4. Run the new tests and existing relevant tests. Review the diff for signature preservation and scope compliance.

Do not broaden accepted inputs, refactor unrelated code, or change callers. Any work requiring broader scope or new access must be proposed separately for owner approval, not performed as part of this task.

Report the changed file paths, the implementation change, test commands, and observed results. Distinguish actual test evidence from unverified expectations.

Judge: the null regression test fails on the original implementation and passes after the fix; preservation tests match native trim() for every tested string; existing relevant tests pass. Pass requires this evidence plus an unchanged public signature, no new dependencies, and a diff confined to this helper and its tests. If tests cannot run, report the fix as unverified rather than claiming a pass.
```
